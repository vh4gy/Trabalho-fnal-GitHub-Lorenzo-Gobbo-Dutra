# Projeto Landing Page - Loja de Papelaria

## Apresentação do Projeto
Este projeto foi desenvolvido como parte da Unidade Curricular do SENAI. Trata-se de uma Landing Page interativa para uma loja de papelaria virtual, apresentando produtos escolares de destaque, estilização com CSS e interatividade via JavaScript.

## Acesso ao Repositório
Você pode acessar o código fonte completo e o histórico de versões diretamente no GitHub através do link:
👉 [Repositório Oficial no GitHub](https://github.com/vh4gy/Trabalho-fnal-GitHub-Lorenzo-Gobbo-Dutra.git)

## Tecnologias Utilizadas
- **HTML5:** Estruturação semântica da página e organização dos produtos.
- **CSS3:** Estilização visual, uso de Flexbox e design responsivo.
- **JavaScript (ES6):** Funcionalidade de alerta interativo para os visitantes.
- **Git & GitHub:** Controle de versão, histórico de branches, resolução de conflitos e tags de release.
